    Quick guide

    This guide stays available through ? Guide in the header or F1. Close it to return to the same map and zoom.

    Open the complete field guide ↗ · Load, edit, save, export and integrate, with a downloadable PDF.

    1. Step 1 — Load. Choose Legends to start in Littleroot, your own files, or a saved draft. Open Legends or a source ZIP. Your repository is never changed by this app.
    2. Step 2 — Studio. The workspace opens in Move so dragging pans safely. The default brush is plain grass when a labelled grass tile exists. Choose a map. Tap a metatile on the right, then paint on the canvas. Fill replaces connected cells with the same metatile ID while preserving movement values.
    3. Map tilesets lets you borrow a compatible primary/secondary pair from another location. Use the searchable category dropdown to browse cliffs, water, signs and other groups; tag unlabelled tiles in Group selected tile.
    4. Review events: run the check from NPCs & events or Export. Findings are advice. Preview a suggested correction before applying it, then use Undo if needed. Optional local AI explains findings after a one-time model download; it does not change source files.
    5. NPCs & events: choose + NPC, then tap the map. Tap its marker later to edit its position, appearance, movement or dialogue. Signs, triggers and warps use the same placement workflow. Event mode pauses tile painting; close its panel to paint again.
    6. Use Pixel studio to change tileset pixels. Select a color index, zoom in, and paint. Changes appear on every loaded map using that sheet.
    7. Step 3 — Export → Share edits ZIP. Upload that ZIP back to chat for conflict-checked integration.

    Find tiles faster: P and S identify the primary and secondary source in each category. Search by name, location, behavior or tile ID. Use Pinned, Used or Recent to narrow the palette; tap the star beside the selected source to pin a brush. Each map opens with its own saved primary/secondary pair and fresh filters. Clear filters restores the whole pair. Category overrides and pins follow their own tileset when you switch pairs.

    Map border: open Map border above the tile palette. Choose a metatile, then tap a pattern cell to paint it. Show around map previews its repeating pattern; border edits have undo and are included in source exports.

    On compact screens, choose maps from the top dropdown. Collision/display, tilesets and events open over the canvas; Done tucks the controls away. The highlighted NPCs & events tab keeps event mode active; tap it again to show its controls or close it to return to tile painting.

    Use Move to pan with one finger. The zoom controls keep pixel edges crisp. Undo/redo works across maps and sheets. Drafts save automatically after editing; Save draft saves immediately. Saved drafts include undo history. Choose Load to browse or delete them. Deleting a draft keeps the open workspace; its next edit or Save draft starts a new draft. Ctrl+Z undoes; Ctrl+Shift+Z redoes.

    Current scope: pokeemerald-style layouts with standard 16-byte metatiles; movement overlays with 32 elevation/collision presets and raw collision values 0–3; Emerald and FRLG layout splits; indexed PNGs; collision/elevation; raw 4bpp and hex ROM editing. NPC/sign/trigger/warp placement and dialogue interactions are supported in source mode. No general script-code editor, map resizing, animation playback, game emulator, automated decompiler, or compressed ROM graphics writeback yet. Source map views are daytime static previews.

    Inspired by Porymap and Hex Maniac Advance. Independent implementation; no affiliation. ZIP compression: fflate (MIT).
