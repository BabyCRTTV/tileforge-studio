    Quick guide

    On compact screens, Tiles opens the brush drawer. Browse & filter tiles collapses to show more artwork. Collision offers Walkable / Blocked brushes that keep height; advanced fields stay inside Advanced movement; tap ? beside controls for a lasting explanation. DeX and larger windows use the available space when resized.

    This guide stays available through ? Guide in the header or F1. Close it to return to the same map and zoom.

    Open the complete field guide ↗ · Load, edit, save, export and integrate, with a downloadable PDF.

    1. Step 1 — Load. Choose Legends to start in Littleroot, your own files, or a saved draft. Open Legends or a source ZIP. Your repository is never changed by this app.
    2. Step 2 — Studio. The workspace opens in Move so dragging pans safely. The default brush is plain grass when a labelled grass tile exists. Choose a map. Tap a metatile on the right, then paint on the canvas. Fill replaces connected cells with the same metatile ID while preserving movement values.
    3. Show all tilesets starts checked in the right-hand painter. Interior/Exterior narrow the project list in one tap. Other pairs preview the whole playable map before explicit Apply, with Undo. Uncheck the box to use active-pair category/pin filters. Tools & tasks → More map tools → Map tilesets lets you borrow a compatible primary/secondary pair from another location. Use the searchable category dropdown to browse cliffs, water, signs and other groups; tag unlabelled tiles in Group selected tile.
    4. Review events: run the check from NPCs & events or Export. Findings are advice. Preview a suggested correction before applying it, then use Undo if needed. Optional local AI explains findings after a one-time model download; it does not change source files.
    5. NPCs & events: choose + NPC, then tap the map. Tap its marker later to see a summary, then choose Edit event to change its position, appearance, movement or dialogue. A tap also inspects markers in Move; dragging still pans. Signs, triggers and warps use the same placement workflow. Event mode pauses tile painting; close its panel to paint again.
    6. Open ☰ Menu → Pixel studio to change tileset pixels. Use Edit palette colors there to change a source palette color. In Map studio, Edit selected metatile rearranges the eight 8×8 pieces, palette banks and flips. Both editors preview first, identify shared source usage and save one Undo entry on Apply. Select a color index, zoom in, and paint. Changes appear on every loaded map using that sheet.
    7. Step 3 — Export → Share edits ZIP. Upload that ZIP back to chat for conflict-checked integration.

    Find tiles faster: P and S identify the primary and secondary source in each category. Search by name, location, behavior or tile ID. Use Pinned, Used or Recent to narrow the palette; tap the star beside the selected source to pin a brush. Each map opens with its own saved primary/secondary pair and fresh filters. Clear filters restores the whole pair. Category overrides and pins follow their own tileset when you switch pairs.

    Map border: open Map border below the tile palette. Choose a metatile, then tap a pattern cell to paint it. Show around map previews its repeating pattern; border edits have undo and are included in source exports.

    On compact screens, choose maps from the top dropdown. View options, tileset setup and area tools open from Tools & tasks. Events use the brush inspector; Tap the top-right × and confirm Close menu to dismiss a tool menu. Done tucks event controls away while keeping event mode active; × closes event mode too. The highlighted Events tab keeps event mode active; tap it again to show its controls or close it to return to tile painting.

    Use Move to pan with one finger, or pinch with two fingers to zoom and pan in any canvas tool. Adding the second finger cancels a pending paint or stamp; lift both fingers before editing again. Fit frames the canvas and resumes automatic fitting. In Map studio, tap Original to view the imported baseline, then Edited to return. Original shows baseline map art, shared tiles/palettes, movement, borders and visible event markers; the canvas is read-only. Your working edits and Undo stay intact. Drag the grip on the tile window’s left edge to resize it. Portrait/landscape panel and phone drawer sizes are remembered on this device. Focus the grip and use Left/Right arrows to resize or Home to reset. Undo/redo works across maps and sheets. Drafts save automatically after editing; Save draft saves immediately. Saved drafts include undo history. Choose Load to browse or delete them. Deleting a draft keeps the open workspace; its next edit or Save draft starts a new draft. Ctrl+Z undoes; Ctrl+Shift+Z redoes.

    Settings → App updates: check the installed and latest versions. On Android, download a verified update inside TileForge and confirm installation in Android. In the browser, Apply web update saves your workspace as a draft and refreshes the editor. Your drafts remain available.

    Areas & stamps: select a rectangle by drag or coordinates, Copy selected area, choose art/movement/both, then Stamp with a tap. Name and Save stamp to reuse it with the same tileset pair. Stamps travel in drafts and editable projects. Ruler measures tile steps; Map PNG exports clean static art.

    Workspace menu: Map studio stays in the navigation bar. Open ☰ Menu for Pixel studio, ROM workspace and Resume draft. Load and Resume draft ask before going home; Keep editing cancels, and Back to studio returns to your open workspace.

    ROM navigation: Hex, search & navigation offers hex/ASCII search, pointer candidates, Back/Forward and bookmarks saved with ROM drafts. Search and navigation do not change bytes. Literal ASCII does not decode Pokémon dialogue.

    Current scope: pokeemerald-style layouts with standard 16-byte metatiles; movement overlays with paired passage/elevation lists and raw collision values 0–3; Emerald and FRLG layout splits; indexed PNGs; collision/elevation; raw 4bpp and hex ROM editing. NPC/sign/trigger/warp placement and dialogue interactions are supported in source mode. No general script-code editor, map resizing, animation playback, game emulator, automated decompiler, or compressed ROM graphics writeback yet. Source map views are daytime static previews.
