A small guide to TileForge

  1. Open Legends or a source ZIP. Your repository is never changed by this app.
  2. Choose a map. Tap a metatile on the right, then paint on the canvas. Fill replaces connected cells with the same full map value.
  3. Map tilesets lets you borrow a compatible primary/secondary pair from another location. Use the searchable category dropdown to browse cliffs, water, signs and other groups; tag unlabelled tiles in Group selected tile.
  4. NPCs & events: choose + NPC, then tap the map. Tap its marker later to edit its position, appearance, movement or dialogue. Signs, triggers and warps use the same placement workflow. Event mode pauses tile painting; close its panel to paint again.
  5. Use Pixel studio to change tileset pixels. Select a color index, zoom in, and paint. Changes appear on every loaded map using that sheet.
  6. Export → Share edits ZIP. Upload that ZIP back to chat for conflict-checked integration.

Use Move to pan with one finger. The zoom controls keep pixel edges crisp. Undo/redo works across maps and sheets. A local draft is saved after editing.

Current scope: pokeemerald-style layouts with standard 16-byte metatiles; movement overlays with 32 elevation/collision presets and raw collision values 0–3; Emerald and FRLG layout splits; indexed PNGs; collision/elevation; raw 4bpp and hex ROM editing. NPC/sign/trigger/warp placement and dialogue interactions are supported in source mode. No general script-code editor, map resizing, animation playback, game emulator, automated decompiler, or compressed ROM graphics writeback yet. Source map views are daytime static previews.

Inspired by Porymap and Hex Maniac Advance. Independent implementation; no affiliation. ZIP compression: fflate (MIT).
